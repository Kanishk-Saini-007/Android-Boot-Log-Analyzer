Android Boot Log Analyzer - full web tool

Analyze real Android boot logs (dmesg or logcat) right here: issues found and classified, boot-stage timing with slow stages flagged, a visual timeline, a transparent 0-100 health score, and the same HTML/JSON reports the CLI writes, ready to download. Compare two boots to see exactly what got fixed. Everything runs in your browser.

This page is a faithful JavaScript port of the Python CLI in the repo - same parser, same rules, same math, with output checked against the CLI itself. Run the original with Python 3.10+: python3 -m bootlog_analyzer your.log

1Pick a sample log, or use your own

The bundled samples are synthetic - hand-written logs with known failures, same ones as the repo's sample_logs/. Your own log never leaves this page. Web limit: up to 1 MB / 20,000 lines per log - for bigger captures use the Python CLI, which has no such limit.

Private by design: analysis runs entirely in your browser. No log data is uploaded anywhere.

1Pick a before and after log

Compare mode answers "did the boot get better or worse?" - which issues were fixed, which are new, and how the time and score moved. Use the synthetic samples or your own two logs (for example one captured before a fix and one after). Your logs never leave this page. Limit per log: 1 MB / 20,000 lines.
